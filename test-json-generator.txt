This changed version of simh emits json-files with (PDP-11) tests.
These tests can be used to verify if your emulator does at least the processor emulation the same as simh does. This assumes that simh has it all correct!

* install libjansson-dev and libssl-dev
* checkout valgen branch
* mkdir build && cd build && cmake .. && make -j4 pdp11-validator-gen

This results in BIN/pdp11-validator-gen. Run that program but only on a system with copieus amounts of ram (at least 48 GB). If it crashes, then you can simply restart it: it will continue where it left off.
The result is 12 GB of json-files, that look like:
